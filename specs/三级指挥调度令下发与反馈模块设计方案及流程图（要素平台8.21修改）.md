# 要素平台三级指挥调度令下发与反馈模块设计方案

## 一、建设背景与痛点

当前支队、大队、中队三级指挥调度指令流转，完全依托 Excel 表格下发、线上文档报送反馈，无标准化流转链路、无系统留痕、无数据统计能力，存在诸多核心痛点：

1、流转低效：人工制表、转发、汇总，层级传递耗时久，紧急调度指令无法快速触达一线中队；

2、管控空白：无法精准统计下发量、签收量、未签收量、反馈量、逾期未反馈量，人员履职情况无数据支撑；

3、纠错缺失：人工派错调度件、下发单位有误时无正规退回流程，只能线下沟通作废，台账混乱；

4、质量不可控：基层反馈内容格式杂乱、要素缺失、内容不规范，无线上驳回整改机制；

5、无闭环管理：指令下发、执行、反馈、办结全流程无系统留痕，无法溯源、无法复盘、无法开展月度考核分析。

为彻底解决以上问题，依托日照交管基础要素平台，搭建三级联动指挥调度令下发反馈模块，实现调度指令一键下发、层级流转、智能签收、规范反馈、错件退回、不合格驳回、全程溯源、自动统计的全闭环数字化管理。

## 二、模块整体设计思路

适配支队（一级）— 大队（二级）— 中队（三级） 垂直指挥架构，采用“逐级下发、分级负责、双向纠错、自动稽核、数据可视”的设计逻辑。

1、权限分层：支队全局下发、大队中转督办、中队落地执行反馈；

2、流程闭环：下发 — 签收 — 执行反馈 — 审核办结，异常工单可退回、可驳回、可整改；

3、智能管控：系统自动计时预警、自动统计台账、自动生成履职报表；

4、替代传统：100% 替代表格下发、文件报送模式，所有流程线上留痕、永久存档。

## 三、核心功能详细设计

### （一）三级派件下发功能

#### 1、下发主体与层级权限

支队指综大队：可全域下发至所有大队、指定大队、指定中队；

大队指综中队：可接收支队指令、转发至本辖区所有 / 指定中队，也可自行下发指令至本辖区所有 / 指定中队，不可跨辖区下发；

中队：无下发权限，仅负责签收、执行、反馈。

#### 2、调度令标准化录入模板

系统内置统一调度令模板，必填要素：添加调度类别（可自定义类别）、调度主题、紧急等级（普通 / 紧急 / 特急）、下发范围去掉、责任单位需要多选（支队层面责任单位为大队，大队层面责任单位为中队）、完成时限（增加7天、30天选项）、调度内容、附件文件、核查要求、反馈要素。杜绝传统表格格式混乱问题。

#### 3、批量 / 定点下发

支持单单位下发、多单位批量勾选下发、按辖区整体下发，下发后系统自动生成唯一调度工单编号，作为全流程溯源唯一标识。

### （二）智能签收与督办功能

1、指令下发后，对应大队、中队后台实时弹窗提醒；

2、接收单位需线上确认签收，系统自动记录签收人、签收时间；

3、未签收工单系统自动倒计时预警，超时未签收标记“逾期未签收”，纳入考核；

4、上级可实时查看下级已签收、未签收、已反馈、未反馈实时状态。

### （三）派错件退回撤销功能（核心纠错功能）

解决人工派单失误、下发单位错误、内容录入错误问题：

1、未签收退回：下发工单后，下级未签收状态下，上级发起“错件退回 / 撤销”，工单直接作废，系统标记“派件错误 - 已撤销”，不纳入有效工单统计；

2、已签收撤回协商：若下级已签收但未反馈，上级可直接发起“退回修改”，下级也可提起“退回修改申请”备注错派原因，上级确认退回后，工单返回初始待下发状态，上级修改内容、更正单位后可重新下发；

3、所有退回、撤销、重发操作全程留痕，记录操作人、操作时间、退回原因，杜绝随意作废工单。

### （四）标准化反馈与不规范驳回功能

实现基层反馈质量可控、统一规范：

1、强制模板反馈：中队 / 大队反馈必须按照系统预设模板填写，包含：落实情况（电话通知、属地上门、缉查布控、非现场录入等）、处置细节（是否处罚、是否撤控）、现场照片、完成进度、存在问题、下一步措施，依据落实情况必填项缺项无法提交；

2、反馈审核机制：下级提交反馈后，由上级调度部门在线审核

反馈规范、要素齐全：审核通过，工单办结；

反馈不规范、内容空洞、缺项漏项、未按要求落实：上级发起“驳回整改”，填写驳回原因，工单退回待反馈状态；

3、限时整改：驳回工单自动重置反馈时限，超期未二次整改标记为履职异常。

### （五）全流程统计分析功能

系统自动聚合所有调度工单数据，生成台账与可视化报表，完全替代人工表格汇总：

基础统计维度：工单总下发数、各级签收数、未签收数、按时反馈数、逾期反馈数、驳回整改数、错件退回数、办结率；违法类别查询、查处数、处罚数、处罚率统计；

分级统计：可按支队整体、各大队、各中队单独统计履职数据；支队账号统计大队数据，点开大队显示中队数据。

3、时间统计：支持日 / 周 / 月 / 季度 / 年度数据筛选；任意时间数据筛选。（违法时间、查询时间等）

4、考核导出：支持一键导出 Excel 考核台账，直接用于队伍绩效考核、工作复盘；

5、异常预警：自动高亮标记长期未签收、未反馈、多次驳回、错派工单。

### （六）全程溯源留痕功能

每一条调度工单留存完整链路日志：录入人、下发人、下发时间、签收人、签收时间、反馈内容、反馈时间、审核人、驳回记录、退回记录、整改记录，实现事事可溯源、件件可核查。

## 四、整体业务流转流程

1、工单创建下发：支队 / 大队管理员录入调度令，选择责任单位，设置时限与等级，正式下发工单；

#### 2、异常前置判断

若发现派件错误：未签收可直接撤销 / 退回，修正后重发；

无错误则进入签收环节；

3、层级签收：大队、中队依次线上签收，系统记录签收时效；

4、基层落实反馈：责任单位按标准化模板填写落实情况、上传佐证，提交反馈工单；

#### 5、上级审核校验

反馈不合格、不规范：驳回整改，基层重新编辑提交；

反馈合格：审核通过；

6、工单办结归档：审核通过后工单自动办结，系统自动归档留存；

7、系统自动统计：每日 / 每月自动更新各级签收、反馈、驳回、错件、逾期数据，生成考核报表。

## 五、模块建设价值

1、去表格化、去文件化：彻底摒弃人工制表、线下报送、人工汇总的传统模式；

2、流程标准化：三级调度指令统一模板、统一流程、统一审核标准；

3、纠错规范化：派错可退、反馈差可驳，解决线下无序整改问题；

4、考核数据化：所有履职情况系统自动统计，公平透明、有据可依；

5、闭环常态化：实现调度指令“下发 - 签收 - 执行 - 反馈 - 审核 - 办结”全闭环管理。
